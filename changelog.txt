[B]Version: 1.1.2[/B]

- Release notes now follow Kodi's interface language: German for German Kodi, English for other languages.
- Revised release notes, removed a provider-specific example and replaced phone-specific wording with mobile device.
- Clarified the separate migration plan for GerXStream and xStream; Baka does not start an automatic data transfer.

[B]Version: 1.1.1[/B]

- Live TV: NITRO is available under Channels by country -> Germany / Austria / Switzerland, now combined into one entry.
- BR, NDR, MDR, rbb, SWR and WDR each appear once. MDR uses Sachsen-Anhalt as its primary source; regional variants remain as fallback sources in the channel information. ZDF, ZDFneo and ZDFinfo remain separate channels.
- Added public DACH internet streams and German- and English-language sports channels. Sports channels are grouped by sport; MagentaTV multicast remains disabled.
- Every TV and sports channel list starts with an EPG for those channels. Programme data comes from the configured XMLTV sources.
- Movies/series, documentaries and anime have independent language profiles. The language prompt appears once during initial setup, without repeating after updates. Order: Do not show, English, German, other languages. Japanese anime audio with German subtitles does not enable English dubbing.
- Settings: main menu options are grouped under Customise menu; WebDAV credentials under Backup destination. The repository add-on remains at 1.0.8.

[B]Version: 1.1.0[/B]

- Baka is the successor to GerXStream (plugin.video.baka, repository.baka) and uses its own add-on ID. A separate migration add-on is planned for transferring existing GerXStream or xStream data; this version does not start an automatic transfer.
- Random selections in every content folder: movies, series, anime, documentaries and children's titles, each with separate genres, result count and minimum IMDb rating. Fixed random movies being limited to early cinema because of TMDB's result cap.
- Languages and regions: choose your languages once on first start. Sources in other languages appear under Other languages or can be hidden; global search only queries sources in your selected languages.
- Streams are filtered and sorted by audio language, with optional original audio and subtitles. Each source declares its languages; the Preferred language setting has been removed.
- My countries: media libraries and live TV grouped by country, with an additional country level when several are selected. Added World cinema with Bollywood, K-drama, Turkish series, Nollywood, telenovelas and more. Fixed category names are now translated.
- Fixed kinox language filtering failing because of an invalid cookie, movie2k search failing for Japanese, weather still images not opening, and shared profiles with live streams in the menu order being rejected.
- Epic-Watchlist: custom watchlists alongside Planned, Watching, Completed and Dropped, each with folders. Play list queues all movies and episodes in Kodi; entries that only point to a search are skipped. Older favourites without a watchlist remain accessible under Favourites.
- Page navigation: Page X of Y (or Page X) appears before Next page; select it to jump to any page.
- Random selections: a new minimum TMDB vote count (default 25) favours titles likely to be available from sources. A list now needs about 25 TMDB requests instead of one per title (250 documentaries in roughly 7 instead of 60 seconds).
- Global search combines matching results from multiple sources.
- JPEG webcams: Stop/Back reliably ends image refreshing.

[B]Version: 1.0.38[/B]

- Configure HTTPS-WebDAV, such as Nextcloud, directly through Backup destination in the import/export menu. Includes destination folder, HTTPS address, username and masked app password; cancelling retains existing settings. Import/export actions return to the backup menu.
- Complete backups or selected sections with optional accounts. Separate account-free settings profiles, favourites/watchlists, history, watched flags and an installable add-on ZIP. Manual cloud snapshots without automatic synchronisation. Google Drive/OneDrive use external synchronised folders, without direct OAuth sign-in.
- Fixed TMDB filmographies: person requests use a valid page; missing biography or birthday fields no longer block the dialogue transition. Movie and series credits replace previous lists, invalid entries are skipped and errors are displayed.
- The playback service no longer triggers an extra Container.Refresh after stopping above 90 percent. Series favourites, episode lists, playback and returning to the same folder and selection after Stop were verified in the preceding Android test build.
- Account backups and local WebDAV credentials remain unencrypted; use private storage and separate app passwords. A real cloud transfer including accounts has not yet been tested with a user account.
- 1.0.37 was a local test build without a public release. The repository remains at 1.0.8.

[B]Version: 1.0.31[/B]

- Random movies first offers Random, By genre or By production company; the default remains 250 movies.
- Random selections use TMDB's dated, released catalogue instead of popularity rankings; date ranges avoid TMDB's page limit. Unknown release dates and adult titles remain excluded.
